# Moon Bunny's Little Star

An original procedural illustration for Make.fun's **Make the cutest picture** bounty (`cutest-picture-01`): a moon bunny cuddling a little golden star against an indigo night sky.

`entry.png` is the reviewed 600 × 600 PNG. `main.py` is its original Codex-created generator and uses only the Python standard library.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

The program writes `output/entry.png`. Without `MAKEFUN_OUTPUT_DIR`, it writes `/output/entry.png`.
